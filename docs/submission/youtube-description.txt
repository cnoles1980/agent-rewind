Your AI agent made a mistake. Agent Rewind helps you find the evidence, understand what happened, and take a clearer debugging report back to your coding agent.

Built for individual AI-assisted builders, Agent Rewind combines local log imports, a visual timeline, run comparison, and NVIDIA Nemotron analysis through Nebius Token Factory.

This 2:40 demo follows a shipping-policy mismatch: the requirement says free shipping at $50 or more, but the recorded policy and code exclude exactly $50. See the evidence, review a saved Nemotron explanation, follow its sources, and copy the report for your agent.

The Codex sample and checkout recordings are labeled synthetic/illustrative examples. The Nemotron report shown is a saved response from a real Nebius request. Replay does not execute tools, and analysis does not apply repairs. Imports stay in the browser; requesting analysis sends the reviewed excerpt.

Public exploration needs no API key. Hosted AI analysis and clip publishing require an invitation; self-hosters configure their own server-side Nebius key. Judge credentials are supplied privately with the submission.
